## 보존 및 배포 변경

`OriginalPreservation.json`은 최초 제공 ZIP과 배포용 소스를 비교한 목록입니다. 기존 기능 코드는 필요한 연결 부분을 수정했으며, 대응 모델을 특정할 수 없는 소품은 유지했습니다. 배포본에서는 기존 맑은 고딕 파일과 해당 .meta만 의도적으로 제거하고 나눔고딕으로 교체했습니다. Unity 임포트 과정에서 일부 URP·프로젝트 설정도 갱신됐습니다.

문서의 방 이미지들은 Unity 카메라 렌더입니다. 최신 화면의 한글은 배포본에서 나눔고딕을 사용합니다. 원본 ZIP과 이전 수정본은 별도로 보존했고, 본 배포는 `ReleaseWork/DExpressive`에서 만들어졌습니다.
