# D-EXPRESSIVE v0.1.0

Windows x64용 1인칭 심리 서사 게임 프로토타입입니다. 압축을 모두 풀고 `DExpressive.exe`를 실행하세요.

- DAY 1~10 대화·선택지·정신력·회귀·저장·엔딩
- URP 실내와 가구, 도시락·휴대폰·신발·냉장고·욕실·쓰레기통 에셋 통합
- 사진 요청에 맞춘 쓰레기통 위치와 의자·모니터 방향 수정
- 식사 기능은 도시락에만 적용
- F키 욕실 문 열기·닫기, 충돌 및 끼임 방지

WASD 이동 / 마우스 시점 / F 조사 / 클릭·1·2 선택 / Esc 메뉴 / F5 저장 / F9 불러오기 / Alt+F4 종료.

검증 범위는 저장소 `docs/VERIFICATION_KO.md`를 참고하세요. 플레이 시간·최소 사양은 별도 측정하지 않았습니다.
