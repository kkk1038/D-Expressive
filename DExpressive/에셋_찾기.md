# 에셋은 여기 있습니다

이 프로젝트에는 실제 3D 모델·텍스처·Unity 재질·프리팹이 포함돼 있습니다. **실행 전용 ZIP에는 에셋이 게임 데이터로 묶이므로 개별 FBX·프리팹 폴더가 보이지 않습니다.** Unity에서 편집할 에셋은 소스 ZIP 또는 통합 ZIP을 열어 확인하세요.

| 찾는 파일 | 프로젝트 안 위치 |
| --- | --- |
| 벽·바닥·천장·침대·책상·의자·창문·문 프리팹 | `Assets/ThirdParty/InteriorKitV1/Prefabs` |
| Interior Kit FBX 원본 | `Assets/ThirdParty/InteriorKitV1/fbx` |
| Interior Kit 텍스처·재질 | `Assets/ThirdParty/InteriorKitV1/textures`, `Materials` |
| 욕실·음식·휴대폰·신발·냉장고·쓰레기통 프리팹 | `Assets/ThirdParty/AdditionalProps/GamePrefabs` |
| 추가 모델의 Unity 메시 | `Assets/ThirdParty/AdditionalProps/Meshes` |
| 추가 모델의 URP 재질 | `Assets/ThirdParty/AdditionalProps/Materials` |
| 추가 모델의 준비된 텍스처·변환 데이터 | `Assets/ThirdParty/AdditionalProps/PreparedInput` |
| 보존된 추가 FBX | `Assets/ThirdParty/AdditionalProps/SourceFBX`, `PreparedFBX` |
| 본편의 프리팹 연결 설정 | `Assets/Settings/InteriorKitGamePalette.asset`, `AdditionalRoomPropsPalette.asset` |
| 실행 시 생성하는 기존 소품의 URP 재질 | `Assets/Resources/Materials/RuntimeRoom.mat` |

추가 모델 중 GLB/glTF는 Unity 네이티브 메시와 프리팹으로 변환했으므로, 모든 모델에 FBX 파일이 따로 존재하는 것은 정상적인 요구 사항이 아닙니다. Unity에서 사용할 때는 GamePrefabs를 먼저 보세요. 원본 ZIP 파일을 확장자만 바꿔 복제하지 않았습니다.

- [에셋별 설명·적용 방법](docs/ASSET_GUIDE_KO.md)
- [전체 에셋 파일 목록 CSV](docs/ASSET_INVENTORY.csv)
- [외부 에셋 출처·조건](THIRD_PARTY_NOTICES.md)
- [클로드에 전달할 프롬프트](docs/CLAUDE_HANDOFF_KO.md)

별도 `DExpressive-Assets.zip`은 에셋을 찾기 쉽게 모은 보조 압축본입니다. 기존 DExpressive 프로젝트를 기준으로 사용하며, 신규 빈 프로젝트에서 게임 전체가 자동 실행되는 패키지는 아닙니다. 소스 ZIP에 이미 같은 에셋이 있으므로 다시 덮어쓸 필요가 없습니다.
