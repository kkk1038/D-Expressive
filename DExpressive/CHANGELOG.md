# 변경 기록

## 0.1.0 — 2026-11-04

- 제출 자료에 에셋 찾기·적용 안내, 에셋 파일/해시 목록, GUID 참조 검사 결과, 클로드 인계용 프롬프트 추가.
- 기존 SampleScene과 DAY 1~10, 1인칭 이동·조사, 대화·선택, 정신력, 저장·체크포인트·회귀, 현관문 엔딩을 유지.
- Interior Kit의 벽·바닥·천장·창문·문과 침대·책상·의자를 기존 방 구조에 통합. 독립 InteriorKitTest 씬 유지.
- 욕실 4개 파트와 세탁기, 냉장고, 음식, 휴대폰, 신발, 플라스틱 쓰레기통 추가. URP 재질·크기·충돌 정리.
- 도시락 식사·소모·복원, 휴대폰 연락, 욕실 씻기·거울, 쓰레기통 정리 기능 연결.
- 쓰레기통을 신발장과 현관문 사이로 이동. 의자 180도·모니터 90도 회전 및 위치 수정.
- 냉장고 식사 상호작용 제거.
- 욕실 문 개폐, 양방향 충돌, 끼임 방지 추가. 기존 현관문 엔딩 동작 유지.
- 배포본 글꼴을 나눔고딕(OFL 1.1)으로 교체하고 Windows 빌드와 문서·GitHub 업로드 구조 추가.
- 실행 파일에서 기존 단순 소품이 분홍색으로 표시되는 문제를 수정. 실행 시 생성하는 방 소품과 날짜별 소품에 패키지에 포함된 URP 재질을 명시적으로 적용.
